Roll-log card redesign — three proposals

All four mockups show the same scenario: Tavik casts Hold Person (Lv 2 slot, concentration save spell) on Bandit Alpha; the bandit fails the WIS save. The full result is: save rolled 8 vs DC 14 (failed), Paralyzed condition installed for 10 rounds, Tavik gains concentration anchor, ↶ Undo available. The first card is what ships today (v2.41.0); the next three are the proposals.

Current — v2.41.0 (what ships today)

Stacked horizontal effect lines. Spell description tucks behind a ▾ details toggle (v2.41.0 addition); everything else is always visible. The card runs 4–5 rows tall for Hold Person; longer for save-for-half spells with damage and concentration-saving stacks. This is the baseline the three proposals improve on.

Proposal 1 — Inline chips, one consequence row

Single horizontal row of pill-shaped chips for every outcome. Tap any chip to expand its sub-detail inline. Densest of the three; best for fast scrolling. Worst for accessibility (tiny tap targets, hard to scan at a glance).

Proposal 2 — Headline + collapsible Result block (recommended)

Headline collapses caster + spell + target into one line. A nested ▼ Result accordion opens automatically when the cast fires and holds every consequence in a label / value grid. The GM folds it once read; the badge in the summary keeps the one-liner verdict at a glance. Spell flavor text stays in a separate ▾ Spell details toggle (v2.41.0 pattern).

Proposal 3 — Minimal card + toast popups

Card collapses to a single audit row: caster + spell + target + override badge. Outcome info moves OUT of the card and into the existing dice-toast system (v2.33.0+), which already pops sequentially for save / damage / heal. HP bar on the mini-sheet + buff chip on the init-tracker row surface the persistent state. Tradeoff: loses scrollback — you can't re-read what happened on turn 3 ten minutes later.

How to read these mockups. Open this file in a browser (works offline, no JS — just static HTML + CSS). The palette and spacing approximate the live tabletop's dark theme but are not pixel-perfect; final styling would adopt the existing CSS variables. The leftmost column in each comparison is what ships today (v2.41.0) — the three columns to its right are the proposals. Tap the ▾ Spell details toggles in Proposal 2 (and on the current card) to see the v2.41.0 collapsible pattern in action.

My recommendation: Proposal 2. It scales cleanly from one-effect spells (Magic Missile damage) to four-effect spells (Hold Person with concentration anchor + paired buff + save result), keeps the audit log scrollable, and reuses the v2.41.0 <details> pattern. The cost is one extra layout pass per card (an outer accordion and an inner flavor-text accordion).
