Unified mini-sheet — visual mockups v2.49.191

Visual companion to the Unified mini-sheet design plan. Three mockups rendered side-by-side (NPC left, PC right). Tabs are clickable, buttons fire toast feedback, spell-slot pips toggle live. v2.49.189–.190: Abilities + Skills merged into a single Stats tab; Resources + Feats merged into a single Features tab; status chips under the HP bar; resistance + immunity chips at the top of the Stats panel.

This is a mockup. Clicking tabs switches local panel visibility; clicking Cast / Strike / Roll fires a corner toast and a no-op. Nothing here talks to the server — the data is hand-authored for design review.
