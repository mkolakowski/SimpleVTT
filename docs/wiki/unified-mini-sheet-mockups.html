Unified mini-sheet — visual mockups v2.49.188

Visual companion to the Unified mini-sheet design plan. Three mockups rendered side-by-side (NPC left, PC right). Tabs are clickable — switch between Actions / Spells / Skills / etc. to see how each design accommodates content density. Cast / Strike buttons trigger a transient toast so the rollover behaviour reads as "real," not as static art.

This is a mockup. Clicking tabs switches local panel visibility; clicking Cast / Strike / skill buttons fires a corner toast and a no-op alert. Nothing here talks to the server — the data is hand-authored for design review.

Current state — baseline (post-v2.49.184)
