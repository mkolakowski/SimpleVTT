✍ Display font

Choose an optional fantasy-style font for headings and body text across the whole app. Leave on System default for the standard UI look.

🔍 Display scale

Make the entire interface or just the text larger or smaller. Saved to your account and applied on every device. Phones (≤ 640 px wide) ignore these settings — phone layouts are already tuned for small screens.

🔭 Tabletop zoom speed

Adjust how fast the tabletop canvas zooms when you use the mouse wheel or pinch on a touch device. Default 1.0 keeps the existing wheel feel; lower values are gentler (good for iPad pinch), higher values are snappier. Applies on every device.

🗂️ Tabletop tab colors

🎞️ Animated GIFs

When enabled, animated GIF portraits play in the character sheet and GIF tokens animate on the tabletop canvas. Disable to show a static first-frame thumbnail instead — useful if motion is distracting during play.
