Scope contract — Jinja includes inherit the caller's local scope: - c → character-like (has id, name). - ab_map → ability score dict {"STR": 12, "DEX": 14, …}; missing abilities default to 10. - skill_map → skill proficiency dict {"Stealth": {"proficient": true, "expertise": false}, …}; missing skills default to {}. - prof → proficiency bonus int. Behavioural contract (preserved verbatim from the inline block): - Bonus calc: ability mod + (prof × 2 if expertise, prof × 1 if proficient, 0 otherwise). - Roll-button data-expr fires through the same .mini-roll-btn handler as the ability buttons in the Stats tab. - Sign-formatted bonus ("+3" / "-1" / "+0") in the displayed mod AND in the rolled expression. #}
